# Форма вызова

Тип функции фиксирует, чем её можно вызвать и что считать результатом. Колбэк в props — такой же контракт.

```ts
type Select = (id: string) => void;

function bind(onSelect: Select) {
  onSelect('u1');
}
```

Необязательный параметр пишут `note?: string`. Вызов без него законен. Это не значит, что внутри аргумент — `null`.

Коротко: _колбэк типизируют так же строго, как публичную функцию_.
