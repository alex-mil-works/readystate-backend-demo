# Форма, а не класс

Объектный тип говорит, какие поля можно читать. Лишние поля у **свежего** литерала — ошибка: вы, скорее всего, опечатались.

```ts
type User = { id: string; name?: string };
const user: User = { id: '1', name: 'Ann' };
```

`name?` значит «поля может не быть». Это не то же самое, что `name: string | null`.

Коротко: _тип объекта — контракт чтения, опциональность — про наличие ключа_.
