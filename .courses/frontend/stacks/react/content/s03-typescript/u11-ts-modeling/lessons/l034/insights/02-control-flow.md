# Сужение по потоку

Компилятор сужает тип после `typeof`, проверки на равенство, `in` и раннего `return`. В другой ветке остаётся дополнение.

Сужение живёт в этой области видимости. Если положить значение в поле объекта и проверить копию, исходное поле может не сузиться — проверяйте то binding, которым пользуетесь.

Коротко: _проверка должна стоять на том же значении, которое вы потом читаете_.
