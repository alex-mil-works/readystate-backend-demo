# `type` и `interface`

Для объектной формы оба работают. `interface` может **дополняться** повторным объявлением с тем же именем — удобно для ambient-типов, опасно для прикладной модели.

Union, intersection и mapped types пишут через `type`. Публичный props-объект компонента чаще оставляют `type`, чтобы его нельзя было тихо расширить из другого файла.

Коротко: _`interface` открыт для слияния, `type` фиксирует выражение_.
