# Что экспортировать

Публичный API — props и, если нужно, тип элемента. Внутренний state, черновик редьюсера и ref наружу не входят.

Не подменяйте `T` на `any`, когда один вызов не выводится. Лучше явный аргумент типа `List<Lesson>` или более узкий constraint `T extends { id: string }`.

Коротко: _снаружи виден контракт props, не кухня компонента_.
