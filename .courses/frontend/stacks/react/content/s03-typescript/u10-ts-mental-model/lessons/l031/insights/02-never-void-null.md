# `never`, `void` и `null`

`never` — тип, у которого нет значений. Им помечают функцию, которая всегда бросает, и ветку `switch`, которая по типам недостижима.

`void` — результат, который вызывающий **не должен использовать**. Это не то же самое, что значение `undefined`.

При `strictNullChecks` `null` не входит в `string` сам. Поле «может отсутствовать» — это `string | null` или опциональное свойство, и это разные модели.

Коротко: _`never` закрывает развилку, `null` надо разрешить явно_.
