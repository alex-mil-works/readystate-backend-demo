# `let` расширяет литерал

`const` держит узкий литеральный тип, если значение не переприсваивают. `let` сразу расширяется: строковый литерал становится `string`, потому что следующее присваивание может его сменить.

```ts
const mode = 'compact'; // 'compact'
let status = 'open';   // string
status = 'closed';
```

Если нужен узкий набор, это union: `let status: 'open' | 'closed' = 'open'`.

Коротко: _ширина типа следует из того, можно ли значение сменить_.
