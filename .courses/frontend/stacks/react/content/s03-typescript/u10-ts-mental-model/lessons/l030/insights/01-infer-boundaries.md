# Вывод внутри, аннотация на границе

Компилятор выводит тип из инициализатора и из контекста вызова. Явная аннотация нужна там, где тип — часть контракта: параметр, публичный возврат, пустой массив, значение без инициализатора.

```ts
const count = 1; // литерал 1
function double(n: number) {
  return n * 2; // возврат выведен как number
}
```

Аннотация на каждом `const` шумит и не делает программу безопаснее.

Коротко: _тип пишут на шве модуля, не на каждой локальной строке_.
