# Прокси страницы

Service Worker живёт отдельно от вкладки. События install и activate готовят новую версию, fetch решает, отдать кэш или сеть. Пока старый worker контролирует клиентов, новый может ждать.

Область действия — путь, под которым его зарегистрировали. Слишком широкий scope перехватывает лишние приложения на том же хосте.

Коротко: _воркер не часть рендера, это политика запросов_.
