# Три полки

`localStorage` и `sessionStorage` — строки на главном потоке; чем они отличаются по вкладкам, разобрано в L027. Сюда не кладут токен, который нельзя светить скрипту, и не кладут большие JSON уроков.

IndexedDB — объекты и индексы, асинхронно. Локальный прогресс, как в этом продукте, живёт здесь. Cache API хранит пары запрос–ответ для воркера, это не таблица пользователей.

Коротко: _полку выбирают по форме данных, не по привычке_.
