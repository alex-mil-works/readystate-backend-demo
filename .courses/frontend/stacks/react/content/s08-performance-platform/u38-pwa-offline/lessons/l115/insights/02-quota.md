# Квота и чужое устройство

Браузер может вытеснить данные сайта, особенно без установки и без устойчивого разрешения. На это не опираются как на единственную копию, если потеря больна.

Профиль браузера общий для человека за этим компьютером, не для его телефона. Пока нет серверной синхронизации, прогресс не «в аккаунте», даже если в интерфейсе есть имя.

Коротко: _локальная полка — этот браузер, не истина всех устройств_.
