# Имя кэша — версия

Кэш без версии копится. Новая поставка кладёт файлы в новое имя и в activate удаляет старые. Отдавать оболочку приложения только из кэша, никогда не сверяясь с сетью, значит не выпускать исправления.

Ошибка в обработчике fetch роняет навигацию даже если сервер жив. Воркер включают, когда стратегия кэша уже названа.

Коротко: _кэш версионируют и умеют выкинуть_.
