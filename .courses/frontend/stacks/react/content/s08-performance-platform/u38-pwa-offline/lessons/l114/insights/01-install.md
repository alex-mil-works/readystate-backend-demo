# Браузер решает, ставить ли

Манифест называет имя, иконки, start_url и режим окна. Страница по HTTPS с воркером может стать устанавливаемой. Кнопку «установить» браузер имеет право не показать: это его жест, не ваш гарантированный CTA.

Установленное окно — всё ещё веб. Права те же, что у вкладки, плюс отдельная иконка.

Коротко: _манифест описывает оболочку, не выдаёт нативных прав_.
