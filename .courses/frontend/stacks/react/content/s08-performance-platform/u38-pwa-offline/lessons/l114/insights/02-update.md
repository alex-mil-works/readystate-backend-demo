# Офлайн и момент обновления

Offline-first значит: экран задуман так, чтобы открыться из кэша и дописать сеть потом. Запасная заглушка «нет сети» проще и честнее, если данные всё равно только с сервера.

Новый воркер лучше показать фразой «доступна версия» и обновить по кнопке или на следующей навигации. Тихая перезагрузка посреди урока теряет ввод.

Коротко: _офлайн проектируют, обновление не воруют у человека_.
