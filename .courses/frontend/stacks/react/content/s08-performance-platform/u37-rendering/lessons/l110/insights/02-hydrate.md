# Та же разметка

Гидрация предполагает, что дерево на клиенте совпало с тем, что прислал сервер. Другое время, случайный id или ветка `window` только на клиенте дают расхождение: React предупреждает и может перерисовать кусок заново.

То, что должно отличаться на клиенте, не участвует в первом серверном HTML либо терпит до эффекта.

Коротко: _гидрация не чинит две правды, она требует одну_.
