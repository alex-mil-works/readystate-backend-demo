# Меньше JS по умолчанию

Astro хорошо живёт как контентный сайт: страницы статичны, React-остров подключают точечно. React Router в режиме фреймворка ближе к приложению с вложенными маршрутами и данными, но это не тот же продукт, что Next.

Выбор зависит от того, приложение это или издание, насколько страницы личные и кто их хостит. Переписывать учебный интерфейс в модный рантайм урок не требует.

Коротко: _инструмент берут под форму сайта, модель UI не выбрасывают_.
