# Не оживлять всю страницу

Остров — кусок, которому нужен клиентский код: поиск, плеер, форма. Остальной документ остаётся HTML без гидрации всего дерева.

Мета-фреймворк продаёт выбор режима по маршруту. Цена — ещё одна модель сборки, свои правила данных и свой хостинг. Её платят, когда режимов несколько. Один статический сайт не обязан тащить комбайн.

Коротко: _интерактивность дозируют, платформу берут под набор режимов_.
