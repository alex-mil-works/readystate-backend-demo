# Кто нарисовал первый HTML

CSR: сервер отдаёт почти пустую оболочку, интерфейс появляется после JavaScript. До скрипта смотреть нечего, зато хостинг статичен.

SSR: сервер уже собирает HTML под этот запрос. Первый байт позже, зато текст есть до большого бандла. Интерактивность всё равно ждёт, пока скрипт скачается и выполнится.

Коротко: _SSR ускоряет первый осмысленный HTML, не отменяет клиентский код_.
