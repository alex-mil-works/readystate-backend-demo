# Платформа, не замена React

Next даёт маршруты, данные и несколько режимов рендера в одном соглашении. Компонент по-прежнему функция от данных. Серверные компоненты убирают их код из браузера, но не отменяют снимок state и эффекты там, где клиент нужен.

Путать «мы на Next» с «мы понимаем рендер» опасно: гидрация, кэш запроса и граница сервера остаются вашими.

Коротко: _фреймворк выбирает, где выполнить дерево, не что такое состояние_.
