# HTML на сборке

SSG кладёт готовый HTML в артефакт сборки. Отдача дешёвая, кэш простой, серверу нечего считать на запрос. Так живут статьи, документация, маркетинг.

Личная лента и цена, которая меняется каждую минуту, к моменту запроса уже врут. Тогда либо страница собирается на запрос, либо статика обновляется по правилу, и вы осознанно терпите окно устаревания.

Коротко: _заранее собирают то, что не уникально для этого запроса_.
