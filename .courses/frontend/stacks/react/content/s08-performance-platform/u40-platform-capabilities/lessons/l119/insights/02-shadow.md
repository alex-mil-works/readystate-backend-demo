# Тень не пускает стили наружу

Shadow DOM прячет внутреннюю разметку. Стили страницы не красят внутренности, стили элемента не вытекают. Наружу торчат атрибуты, слоты и события.

React привык к свойствам и синтетическим событиям. Граница с теневым элементом чаще атрибуты и обычные DOM-события. Это терпимо на крае дизайн-системы и больно, если весь экран переписать на теги ради изоляции, которую и так даёт модуль CSS.

Коротко: _тень — капсула виджета, не новая модель приложения_.
