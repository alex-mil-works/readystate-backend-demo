# Ключ вместо записанного пароля

WebAuthn и passkey: сайт хранит открытый ключ, закрытый остаётся у платформы. Вход — подпись челленджа, не строка, которую можно вытащить из localStorage.

Фронтенд начинает церемонию и показывает запасной вход. Проверку подписи делает сервер. Это не «пароль, только в новом поле».

Коротко: _секрет ключа не лежит в JavaScript_.
