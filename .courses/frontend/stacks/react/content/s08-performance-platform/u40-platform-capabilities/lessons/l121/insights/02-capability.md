# Сначала обнаружить

Payment Request показывает знакомый диалог способов оплаты, если они есть. Номера карты в вашу базу из этого урока не следуют: граница карточных данных остаётся у платёжного провайдера, не в состоянии React.

Перед кнопкой проверяют, есть ли API. Нет — обычная форма или переход туда, где оплата уже умеет жить. Так же с входом по ключу.

Коротко: _возможность обнаруживают, деградация заранее нарисована_.
