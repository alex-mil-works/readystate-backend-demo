# Три состояния и запасной путь

Разрешение бывает ещё не спрошено, дано и отклонено. Отклонённое не лечат циклом запросов. Рядом остаётся путь без этой возможности: ввести город руками, не слать уведомления, загрузить файл вместо камеры.

Многие API живут только в безопасном контексте. На голом http их нет, и это не баг телефона.

Коротко: _возможность обнаруживают, отказ уважают, сценарий не стоит на одном диалоге_.
