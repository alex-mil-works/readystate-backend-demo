# Тег со своим классом

Custom Element — класс, который браузер связывает с именем тега. Жизнь элемента: его добавили в документ, атрибуты меняются, его убрали. Шаблон `template` держит разметку, которую можно клонировать, не показывая её сразу.

Имя тега содержит дефис, чтобы не столкнуться с будущим HTML.

Коротко: _свой тег — обычный DOM-узел с вашим классом_.
