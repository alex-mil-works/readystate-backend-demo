# Поле, не один прогон

Лабораторный прогон — ваша машина и искусственная сеть. Полевые данные — распределения реальных визитов: медиана и хвост. Чинить имеет смысл хвост, если там люди, а не гнаться за баллом одного отчёта.

Улучшение LCP картинкой не лечит INP. Сначала называют симптом, потом причину.

Коротко: _метрика указывает класс проблемы, не строку, которую надо микрооптимизировать_.
