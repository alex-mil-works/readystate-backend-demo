# Порядок, не заклинание

RAIL напоминает масштаб: ответ на жест ощущается до сотни миллисекунд, кадр анимации укладывается в интервал кадра, тяжёлую работу откладывают на простой, загрузка не блокирует лишним.

PRPL напоминает поставку: сначала критичное, остальное лениво, оболочку можно положить в кэш, чтобы повторный заход был дешевле. Это не обязательный чеклист из четырёх букв на каждый проект.

Коротко: _сначала предел и измерение, потом приём из модели_.
