# Предел до спора

Бюджет говорит: первый JS не толще N, картинка героя не тяжелее M, LCP не хуже порога на синтетике. Без числа любой новый пакет «почти ничего не весит».

Регрессию ловят в CI сравнением размера чанка или лабораторного прогона с базой. Падение на пару килобайт не повод блокировать релиз. Скачок первого экрана — повод.

Коротко: _бюджет спорит цифрой в запросе на слияние, не вкусом после деплоя_.
