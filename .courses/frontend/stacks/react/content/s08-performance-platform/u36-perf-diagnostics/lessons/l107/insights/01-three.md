# Три разных жалобы

LCP — момент, когда отрисовался самый крупный элемент в зоне первого экрана: чаще картинка, заголовок или блок текста. Это про загрузку главного, не про весь сайт.

CLS — насколько элементы прыгают сами, без участия человека. Дырка под картинку без размера, шрифт, который подменил строку, вставленная плашка сверху.

INP — задержка от действия до следующего кадра, по худшим взаимодействиям за визит. Долгий обработчик клика портит INP, даже если LCP уже хороший.

Коротко: _загрузка, устойчивость и отклик измеряют отдельно_.
