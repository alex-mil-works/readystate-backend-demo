# Не хранить вычисленное

Полное имя из `first` и `last`, число отфильтрованных строк, «все выбраны» — считаются во время рендера. Второй `useState` плюс эффект, который его догоняет, рано или поздно разъедется.

```jsx
const visible = lessons.filter((lesson) => lesson.stageId === stageId);
```

Держать в state стоит источник: ввод пользователя, выбор, ответ сервера. Не его проекцию.

Коротко: _derived value живёт в теле рендера_.
