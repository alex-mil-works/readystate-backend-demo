# Новая ссылка, старые поля

Мутация объекта в state часто не меняет ссылку. React может не увидеть обновление, а прошлый снимок окажется испорчен.

```jsx
setUser({ ...user, name: nextName });
```

Вложенное поле тоже копируют по пути: новый объект родителя и новый вложенный объект. Массив — `map` или копия с заменой элемента, не `push` в старый.

Коротко: _следующий state — новое значение, прошлое не трогаем_.
