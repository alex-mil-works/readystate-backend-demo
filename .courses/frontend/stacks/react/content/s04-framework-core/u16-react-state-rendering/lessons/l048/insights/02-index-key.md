# Почему индекс врёт

Key по индексу совпадает с позицией. Удалили первую строку — бывшая вторая становится первой и наследует её локальный state: поле ввода, раскрытие, черновик.

```jsx
{lessons.map((lesson) => (
  <Row key={lesson.id} lesson={lesson} />
))}
```

Индекс допустим только у статичного списка без перестановок и локального state. Для данных с сервера берите id.

Коротко: _key стабилен, пока жива сущность, и уникален среди соседей_.
