# Сверка двух деревьев

Между рендерами React сравнивает новое описание с прошлым. Тот же тип компонента на том же месте сохраняет state. Другой тип — state сбрасывается.

У списка братьям нужен стабильный `key`. Иначе «тот же индекс» считается той же личностью, даже если внутри другая строка.

Коротко: _позиция и key отвечают, чей это state_.
