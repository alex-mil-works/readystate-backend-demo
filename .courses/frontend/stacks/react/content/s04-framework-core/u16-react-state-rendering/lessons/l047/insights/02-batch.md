# Несколько обновлений одного снимка

Два вызова `setN(n + 1)` в одном обработчике оба читают один и тот же `n`. Итог — +1, не +2.

Если следующее значение зависит от предыдущего, передают функцию: `setN((prev) => prev + 1)`. React применит её к актуальному очереди, а не к закрытому снимку.

Коротко: _от снимка считают один раз, от предыдущего state — через updater_.
