# Порядок лечения

1. Опустить state к тем, кто его показывает.
2. Не хранить производное и не зеркалить его эффектом.
3. Стабилизировать ссылки, если memo или эффект от них зависит.
4. Только потом дробить memo по дереву.

Виртуализация длинного списка и отложенный ввод — отдельные приёмы, когда замер показал стоимость раскладки, а не «на всякий случай».

Коротко: _мемоизация без профайлера лечит не ту строку_.
