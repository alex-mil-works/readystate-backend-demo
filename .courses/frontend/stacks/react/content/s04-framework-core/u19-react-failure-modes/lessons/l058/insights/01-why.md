# Кто попросил рендер

Компонент рендерится заново, если сменился его state, props или рендерится родитель и не отсёк обновление. Профайлер показывает, какой коммит это сделал и сколько он занял.

Частый рендер дешёвого текста — не проблема. Частый рендер большого дерева из-за поля поиска в корне — проблема размещения state. Полевой LCP, CLS и INP и запись сети — это уже S08, не этот урок: здесь ищут, какой state React перерисовал дерево.

Коротко: _вопрос не «сколько раз», а «дорого ли и из-за какого state»_.
