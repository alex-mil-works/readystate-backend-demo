# Событие и бесконечный цикл

Запрос по кнопке, который завернули в эффект от флага `submitted`, легко забудет сбросить флаг и уйдёт вторым кругом. Обработчик submit вызывается ровно в момент события.

Другой провал: эффект без массива зависимостей или с объектом, который сам создаёт, вызывает setState. Каждый рендер стартует эффект снова.

Коротко: _эффект без условия остановки — цикл рендеров_.
