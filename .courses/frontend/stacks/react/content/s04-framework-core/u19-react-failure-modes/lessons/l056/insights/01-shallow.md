# Сравнение ссылок

`React.memo` пропускает рендер, если каждый prop — тот же по `Object.is`. Числа и строки сравниваются по значению. Объект, массив и функция — по ссылке.

```jsx
<Row style={{ color: 'red' }} onPick={() => pick(id)} />
```

Оба пропа новые каждый рендер родителя. Memo внутри Row ничего не сэкономит.

Коротко: _мемоизация ребёнка бесполезна, если родитель каждый раз даёт новые ссылки_.
