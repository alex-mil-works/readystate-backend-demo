# Не зеркалить props

Эффект «если изменился user, сделать setUser» хранит вторую копию. Между рендерами она врёт, а лишний setState рендерит снова.

Нужна копия, только если пользователь дальше редактирует черновик. Тогда это уже другой state, и его сбрасывают явно — часто через `key` на форме, а не вечным эффектом.

Коротко: _props уже есть в рендере, вторая копия должна иметь свою причину_.
