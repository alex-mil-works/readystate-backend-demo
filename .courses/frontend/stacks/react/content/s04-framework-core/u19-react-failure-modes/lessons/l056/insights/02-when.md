# Когда стабилизировать

`useMemo` и `useCallback` сохраняют ссылку, пока не изменились зависимости. Их берут, когда ссылку сравнивает memo-ребёнок, зависимость эффекта или дорогой расчёт, который вы уже измерили.

Оборачивать каждый обработчик заранее только шумит. Сначала опускают state ниже, чтобы родитель реже рендерился.

Коротко: _сначала граница state, потом стабильная ссылка, потом memo_.
