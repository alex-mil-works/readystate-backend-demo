# Адрес — это состояние

Путь и query говорят, какой экран открыт: курс, урок, фильтр. Обновление страницы и чужая ссылка должны попасть в то же место.

```text
/courses/frontend/react/lessons/L044-react-elements-jsx
```

Если параллельно хранить `currentLesson` в state и забывать писать его в адрес, кнопка «назад» и ссылка разъедутся с экраном.

Коротко: _чем можно поделиться, то живёт в URL_.
