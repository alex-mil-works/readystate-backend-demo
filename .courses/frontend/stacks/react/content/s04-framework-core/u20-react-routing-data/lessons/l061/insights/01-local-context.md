# Сначала ближе к дереву

Поле, раскрытие, черновик — useState там, где их рендерят. Context оправдан, когда значение нужно далеко внизу и меняется редко: тема, локаль, текущий пользователь.

Любое изменение value у провайдера рендерит потребителей. Класть туда каждый символ поиска — снова широкий рендер, только через контекст.

Коротко: _Context — зависимость дерева, не глобальная переменная на всё_.
