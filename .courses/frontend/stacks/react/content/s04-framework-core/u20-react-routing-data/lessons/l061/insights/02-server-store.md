# Серверные данные отдельно

Ответ API — не такой же state, как открыта ли модалка. У него есть ключ запроса, устаревание, повтор, отмена. Это кэш. Его можно держать в небольшом модуле или в библиотеке вроде TanStack Query. Суть не в бренде, а в том, что UI-state и кэш запроса не смешивают в одном useState корня.

Внешний store нужен, если одни данные читают и не-React код, или обновления очень частые и точечные. Пока хватает ближайшего родителя, store не заводят.

Коротко: _модалка локальна, сессия редкая и широкая, ответ сервера — кэш_.
