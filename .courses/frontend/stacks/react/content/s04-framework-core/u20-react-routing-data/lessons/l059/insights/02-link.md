# Ссылка, а не самодельная история

Переход — `<a>` или Link роутера, который меняет history без перезагрузки. `pushState` сам по себе не рассказывает React, что пора рендерить другой экран: это делает роутер, слушающий адрес.

Фильтр, который не жалко потерять при обновлении, может остаться локальным state. Фильтр, который шлют коллеге, — search params.

Коротко: _роутер читает адрес, компоненты читают роутер_.
