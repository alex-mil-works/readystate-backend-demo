# Синхронизация, не жизненный цикл

Эффект нужен, когда React-дерева недостаточно: подписка, таймер, запрос, чужая библиотека. Он не замена `componentDidMount` «на всякий случай».

Посчитать значение из props и нарисовать его — работа рендера. Реакция на клик — обработчик. Эффект — если после появления на экране нужно договориться с миром снаружи.

Коротко: _эффект отвечает на вопрос «с чем компонент сейчас синхронизирован»_.
