# Обновление от предыдущего

Клик «ещё» и ответ сети могут встать в одну очередь. Закрытый снимок устареет. Функция получает значение, которое уже накопила очередь.

```jsx
setCount((prev) => prev + 1);
```

Несколько таких хуков в одном компоненте независимы. Общий state нужен только если обновления должны быть одним снимком.

Коротко: _updater нужен, когда новое значение — функция старого_.
