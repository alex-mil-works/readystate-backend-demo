# Хук помнит слот

React связывает каждый вызов `useState` с компонентом по порядку. Поэтому хуки нельзя прятать в `if` или цикл: слот съедет, и чужой state попадёт не в ту переменную.

```jsx
const [query, setQuery] = useState('');
const [open, setOpen] = useState(false);
```

Начальное значение читается в первый раз. Дальше живёт то, что вы положили через set.

Коротко: _порядок хуков стабилен, начальное значение — только старт_.
