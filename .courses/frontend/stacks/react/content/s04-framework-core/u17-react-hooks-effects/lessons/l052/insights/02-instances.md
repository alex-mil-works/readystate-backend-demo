# Каждый вызов независим

Два `useToggle()` — два state. Хук не шарит данные между компонентами сам по себе. Общее состояние по-прежнему поднимают к владельцу или во внешний store.

Имя с `use` нужно и людям, и линтеру: он проверит порядок вызовов.

Коротко: _вызов хука — отдельный экземпляр слотов_.
