# Зависимости и уборка

Массив зависимостей перечисляет значения из рендера, которые эффект использует. Пропуск — это сознательная ложь: внутри останется старый снимок.

```jsx
useEffect(() => {
  const id = setInterval(() => onTick(), delay);
  return () => clearInterval(id);
}, [delay, onTick]);
```

Cleanup вызывается перед следующим запуском и при размонтировании. Без него интервал и подписка живут после ухода экрана.

Коротко: _каждая синхронизация умеет отмениться_.
