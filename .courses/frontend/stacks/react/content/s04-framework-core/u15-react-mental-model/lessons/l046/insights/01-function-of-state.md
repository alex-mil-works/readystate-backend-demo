# Что показать, а не как дойти

Императивный код помнит шаги: создать узел, поменять текст, повесить класс. Декларативный возвращает дерево для текущего состояния. React сам решает, какие узлы обновить.

```jsx
function Status({ saving }) {
  return <p>{saving ? 'Saving…' : 'Saved'}</p>;
}
```

Не нужно хранить прошлый текст и вручную заменять его. Следующий рендер просто опишет другую строку.

Коротко: _рендер отвечает на вопрос «что на экране при этих данных»_.
