# Край, где DOM всё ещё нужен

Фокус, выделение, размер, интеграция с картой или плеером — это уже не описание дерева. Их делают в обработчике или в эффекте синхронизации, не посреди расчёта JSX.

Если и состояние React, и ручные правки одного узла говорят разное, экран разъедется. Источник правды должен остаться один.

Коротко: _императивный DOM — адаптер на границе, не вторая модель UI_.
