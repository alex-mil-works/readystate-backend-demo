# Вход только вниз

Родитель передаёт props. Ребёнок их читает и не переписывает: следующий рендер родителя всё равно затрёт локальную правку.

```jsx
function Name({ value }) {
  return <span>{value}</span>;
}
```

Сообщить наверх можно только колбэком, который родитель сам передал. Это не второй канал данных, а просьба изменить состояние владельца.

Коротко: _владелец данных один, остальные получают снимок_.
