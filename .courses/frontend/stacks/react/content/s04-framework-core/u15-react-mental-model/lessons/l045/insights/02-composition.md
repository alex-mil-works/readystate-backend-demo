# Сборка, а не иерархия классов

Вариант UI — это другой набор детей и props, а не подкласс кнопки.

```jsx
function Panel({ children }) {
  return <section className="panel">{children}</section>;
}
```

`children` и именованные слоты оставляют содержимое родителю. Компонент задаёт рамку, не закрытый набор внутренних экранов.

Коротко: _composition оставляет решение о содержимом снаружи_.
