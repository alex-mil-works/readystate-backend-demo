# Компонент — функция описания

Компонент вызывают, чтобы получить следующее описание. Имя с большой буквы говорит React: это функция, а не HTML-тег.

```jsx
function SaveButton() {
  return <button type="button">Save</button>;
}
```

Тело компонента должно быть расчётом описания от входных данных. Запросы, подписки и `document.getElementById` в этом теле смешивают описание с побочным эффектом.

Коротко: _рендер считает описание, эффекты живут отдельно_.
