# Событие формы

Отправка — `onSubmit` на `<form>`, не клик по кнопке в обход формы. `preventDefault` отменяет полную перезагрузку страницы.

Кнопка с `type="submit"` активируется и с клавиатуры. Отдельный `onClick` на div этого не даёт.

Коротко: _форма — событие submit, поле — событие change_.
