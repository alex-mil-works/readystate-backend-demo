# Бокс мимо рендера

`useRef` возвращает один и тот же объект `{ current }` на всё время компонента. Запись в `current` не планирует рендер.

```jsx
const inputRef = useRef(null);
function focus() {
  inputRef.current?.focus();
}
```

Пока React не запишет узел, `current` равен `null`. Поэтому фокус ставят в обработчике или эффекте, не рассчитывают на него в первом проходе рендера.

Коротко: _ref — ручка к узлу, не состояние экрана_.
