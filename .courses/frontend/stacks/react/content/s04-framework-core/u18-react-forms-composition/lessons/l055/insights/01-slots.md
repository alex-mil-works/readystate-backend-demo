# Слоты вместо флагов

Компонент с десятком булевых props «покажи заголовок, кнопку, иконку» знает слишком много о чужих экранах. Слот оставляет выбор снаружи.

```jsx
function Dialog({ title, children, actions }) {
  return (
    <section>
      <h2>{title}</h2>
      {children}
      <footer>{actions}</footer>
    </section>
  );
}
```

Именованный `actions` — такой же props, как children. Родитель собирает кнопки, диалог только ставит их в подвал.

Коротко: _рамка не импортирует содержимое всех продуктов_.
