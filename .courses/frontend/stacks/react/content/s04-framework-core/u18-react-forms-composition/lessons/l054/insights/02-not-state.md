# Что не класть в ref

Имя пользователя, открыта ли панель, список уроков — это то, от чего зависит JSX. Если положить их только в ref, экран не узнает об изменении.

Ref уместен для id таймера, прошлого значения «для сравнения» и экземпляра библиотеки, которая сама рисует в переданный элемент.

Коротко: _видно на экране — state; нужно позвать императивно — ref_.
