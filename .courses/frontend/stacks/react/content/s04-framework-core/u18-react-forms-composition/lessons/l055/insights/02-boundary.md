# Где провести границу

Новый компонент окупается, если у него своё имя в разговоре, свой state или его сложно читать вперемешку с родителем. Резать каждый span заранее не нужно.

State поднимают к ближайшему владельцу, которому он нужен двум детям. Ниже — props. Выше без нужды — лишние рендеры всего поддерева.

Коротко: _владелец state — ближайший общий родитель, не корень приложения_.
