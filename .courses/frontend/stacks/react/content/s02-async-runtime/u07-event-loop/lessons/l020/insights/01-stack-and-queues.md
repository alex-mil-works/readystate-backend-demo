# Стек и две очереди

JavaScript в странице выполняет **один** call stack. Пока функция не вернулась, другая ваша функция не начнётся.

Откуда берётся следующая работа:

| Очередь            | Примеры                                                 |
| ------------------ | ------------------------------------------------------- |
| Microtasks         | `Promise.then`, `queueMicrotask`, rejection tracking    |
| Tasks (macrotasks) | `setTimeout`, `setInterval`, события ввода, I/O-колбэки |

Коротко: _промис не «бежит параллельно» — его колбэк ждёт, пока стек опустеет_.
