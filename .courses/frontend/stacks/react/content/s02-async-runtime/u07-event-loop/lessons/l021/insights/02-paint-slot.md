# Где живёт отрисовка

Браузер может обновить кадр **после** того, как текущая task и её микрозадачи закончились, и **до** следующей task.

`requestAnimationFrame` попадает в этот слот отрисовки: колбэк перед ближайшим кадром, не в очередь `setTimeout`.

`queueMicrotask` и `Promise.then` выполняются раньше кадра. Если в микрозадаче читать layout (`offsetHeight`) и тут же менять стиль, легко получить лишний reflow в том же кадре.

Практическое следствие: анимация, привязанная к таймеру 16 мс, промахивается мимо кадра. Кадр — это rAF. Таймер — это «когда-нибудь после задержки».
