# Путь события

Клик по кнопке внутри формы не «случается только на кнопке». Путь такой:

1. **Capture** — от `window` вниз до цели.
2. **Target** — слушатели самой цели.
3. **Bubble** — обратно вверх, если событие пузырится.

`event.target` — узел, где жест начался. `event.currentTarget` — узел, на котором висит **этот** слушатель.

| Вызов                      | Эффект                                                                           |
| -------------------------- | -------------------------------------------------------------------------------- |
| `stopPropagation`          | дальше по пути событие не идёт, другие слушатели **этого** узла ещё работают     |
| `stopImmediatePropagation` | обрывает и остальных на этом узле                                                |
| `preventDefault`           | отменяет действие браузера (submit, переход по ссылке), путь сам по себе не рвёт |

Не всё пузырится. `focus`, например, наверх не идёт — для делегирования берут `focusin`.
