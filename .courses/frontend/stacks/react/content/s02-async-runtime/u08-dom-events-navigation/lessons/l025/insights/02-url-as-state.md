# URL как источник правды

Состояние экрана, которым хочется поделиться и вернуться назад, лучше держать в URL: путь, query, иногда hash.

Объект `state` в истории **не** сериализуется в ссылку. Его видит только эта сессия, и он пропадает, если человек скопировал адрес. В `state` нельзя класть функции и DOM-узлы — браузер клонирует данные structured clone и может отказать.

Типичная связка:

1. Жест меняет URL через `pushState` или через роутер, который делает это сам.
2. Обработчик `popstate` (или роутер) читает **новый** URL и рисует экран заново.
3. Не дублируйте правду в закрытой переменной, которую назад не восстановит.

Роутер фреймворка — надстройка над History API, не отдельный вид навигации. Если сервер не знает про клиентский путь, прямой заход на `/orders/2` отдаст 404, пока хостинг не отдаёт `index.html` на неизвестные пути.
