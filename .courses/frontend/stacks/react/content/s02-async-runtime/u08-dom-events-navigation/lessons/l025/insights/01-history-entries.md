# Запись истории — не переход по сети

`history.pushState(state, '', url)` добавляет запись в стек сессии и меняет адресную строку. Документ **не** перезапрашивается. `popstate` при этом **не** стреляет.

`replaceState` подменяет текущую запись, кнопка «назад» её не покажет отдельно.

`popstate` приходит, когда пользователь идёт назад или вперёд по уже существующим записям. В `event.state` лежит объект, который вы положили в `pushState`, либо `null`.

`location.href = ...` и `location.assign` — это уже **навигация**: браузер грузит документ (если URL другой). Это не тот же механизм, что `pushState`.

Коротко: _pushState двигает URL внутри документа, assign покидает его_.
