# Дерево узлов, не разметка

После разбора HTML браузер держит **дерево узлов**: элементы, текст, комментарии. `document` — корень API, не «файл страницы».

Одни коллекции живые, другие — снимок:

| API                                 | Что возвращает                                 |
| ----------------------------------- | ---------------------------------------------- |
| `getElementsByTagName` / `children` | живая коллекция, видит следующие правки дерева |
| `querySelectorAll`                  | статический `NodeList` на момент вызова        |

Узел можно перенести (`append`) — это тот же объект, не копия. Дерево React и DOM — разные деревья: фреймворк потом **согласует** своё описание с узлами браузера. Прямая правка узла, которым владеет фреймворк, расходится с его следующим рендером.

Коротко: _DOM — объекты браузера с идентичностью, HTML — только их сериализация_.
