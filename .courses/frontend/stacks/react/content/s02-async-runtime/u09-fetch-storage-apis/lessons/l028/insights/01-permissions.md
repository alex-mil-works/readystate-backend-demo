# Спросить состояние — не значит спросить пользователя

`navigator.permissions.query({ name })` читает **текущее** состояние: `granted`, `denied` или `prompt`. Само по себе оно диалог не открывает. Поддержка имени разрешения зависит от браузера; неизвестное имя отклоняет промис.

Диалог открывает уже конкретный API в ответ на жест: `Notification.requestPermission()`, `getUserMedia`, геолокация. Вызов без жеста браузер может заблокировать или отложить.

Отказ пользователя не стоит тут же спрашивать снова. `denied` означает «не предлагать, пока человек сам не сменит настройку».

Проверка `'geolocation' in navigator` говорит, что API **есть в движке**, а не что им можно пользоваться. Это feature detection, не permission.

Коротко: _сначала возможность, потом состояние, и только по жесту — запрос_.
