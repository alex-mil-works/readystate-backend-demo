# Скрытая вкладка — другой режим

`document.hidden` и событие `visibilitychange` говорят, виден ли документ. Скрытая вкладка — повод остановить опрос, паузу анимации и лишние `fetch` по таймеру.

Браузер и так зажимает таймеры в фоне. Свой поллинг поверх этого сажает батарею и путает пользователя, когда вкладка снова видна и пачка ответов приезжает разом.

```js
document.addEventListener('visibilitychange', () => {
  if (document.hidden) stopPolling();
  else refreshOnce();
});
```

Page Visibility не заменяет `AbortController`. Уход со страницы и скрытие вкладки — разные события: первое рвёт работу, второе её приостанавливает.

Тот же приём у Capability API вроде Wake Lock или картинка-в-картинке: сначала проверьте, что API есть, запрашивайте по жесту и отпускайте ресурс, когда он больше не нужен.
