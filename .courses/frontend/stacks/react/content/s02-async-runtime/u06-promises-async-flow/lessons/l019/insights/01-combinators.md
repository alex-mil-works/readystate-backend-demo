# Четыре способа дождаться группы

| Метод                | Fulfilled                                                 | Rejected                                 |
| -------------------- | --------------------------------------------------------- | ---------------------------------------- |
| `Promise.all`        | массив values в исходном порядке, когда все успешны       | сразу на первом rejection                |
| `Promise.allSettled` | массив `{status, value/reason}` всегда, когда все settled | не отклоняется из-за элементов           |
| `Promise.race`       | исход первого settled, каким бы он ни был                 | тоже первый settled, если это rejection  |
| `Promise.any`        | value первого fulfilled                                   | `AggregateError`, если fulfilled не было |

`all` не отменяет остальные запросы, когда один упал. Они продолжают жить, просто их результат вам уже не отдадут.

Коротко: _combinator выбирает политику ожидания, а не запускает работу_.
