# Промис стартует до combinator

`fetch(url)` начинает запрос **в момент вызова**. `Promise.all` только подписывается на уже созданные промисы.

```js
const a = fetch('/a');
const b = fetch('/b');
const [ra, rb] = await Promise.all([a, b]);
```

Оба запроса идут одновременно. А вот так — последовательно:

```js
const ra = await fetch('/a');
const rb = await fetch('/b');
```

Это concurrency на одном потоке: операции **перекрываются по времени ожидания**, но JS не выполняет два ваших колбэка одновременно. Сеть и диск ждут снаружи, колбэки всё равно встают в очередь event loop.

В UI это разница между «панель дождалась всех виджетов» и «запросы случайно встали в очередь».
