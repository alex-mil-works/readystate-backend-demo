# Четыре ступени

Каскад сравнивает объявления по очереди: происхождение (браузер, пользователь, автор), слой, важность (`!important` в конце спора), специфичность, порядок в коде.

Два одинаковых класса: победит тот, что ниже. Класс против элемента: победит класс, даже если элемент написан позже. `!important` ломает этот спор и обычно означает, что специфичность уже запутана.

Коротко: _сначала вес правила, потом его место в файле_.
