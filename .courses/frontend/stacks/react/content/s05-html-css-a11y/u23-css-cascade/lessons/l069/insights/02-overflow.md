# Что не влезло

`overflow: visible` выпускает содержимое наружу и может наехать на соседей. `hidden` обрезает. `auto` даёт прокрутку, только если нужно.

Вертикальные margin соседей схлопываются: два по 16px между абзацами не всегда дают 32. Padding или border между ними схлопывание останавливает. У flex и grid схлопывания margin уже нет.

Коротко: _overflow — политика обрезки, не способ спрятать фокус_.
