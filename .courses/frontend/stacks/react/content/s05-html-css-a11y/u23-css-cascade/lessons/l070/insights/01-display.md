# Как блок лежит в потоке

`block` занимает строку целиком. `inline` сидит в строке текста и игнорирует ширину и вертикальные margin. `inline-block` остаётся в строке, но принимает width и height.

`display: none` убирает бокс и из отрисовки, и из дерева доступности. `visibility: hidden` оставляет пустое место и тоже прячет от скринридера. Это не способ «слегка пригасить» кнопку.

Коротко: _none — элемента нет, hidden — дырка на его месте_.
