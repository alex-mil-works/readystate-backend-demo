# Что течёт вниз

Наследуются в основном текст: `color`, `font`, `line-height`. Не наследуются `margin`, `padding`, `border`, `background`. Их задают на самом блоке.

```css
.card { color: #222; }
.card button { color: inherit; }
```

`inherit` явно берёт значение родителя. Удобно для кнопки, которая должна быть цвета текста карточки, а не синей по умолчанию браузера.

Коротко: _коробка сама по себе, текст часто от родителя_.
