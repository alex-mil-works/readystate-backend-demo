# Контекст наложения

`z-index` сравнивает братьев внутри одного stacking context. Новый контекст создают, например, `position` вместе с z-index не `auto`, `opacity` меньше 1, `transform`.

Меню с `z-index: 9999` внутри карточки с `transform` не перекроет модалку снаружи: оно спорит только с соседями внутри карточки.

Коротко: _большой z-index не выпрыгивает из чужого контекста_.
