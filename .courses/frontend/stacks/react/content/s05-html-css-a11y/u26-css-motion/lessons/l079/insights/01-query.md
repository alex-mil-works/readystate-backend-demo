# Системная настройка

У человека может кружиться голова от параллакса и больших сдвигов. `prefers-reduced-motion: reduce` — его настройка, не каприз.

```css
@media (prefers-reduced-motion: reduce) {
  .panel { transition: none; }
}
```

Декоративный переход убирают или сокращают до мгновенной смены состояния. Короткий фокус на поле с ошибкой иногда оставляют: это польза, не украшение, и её дублируют текстом.

Коротко: _настройка reduce отменяет декор, не смысл_.
