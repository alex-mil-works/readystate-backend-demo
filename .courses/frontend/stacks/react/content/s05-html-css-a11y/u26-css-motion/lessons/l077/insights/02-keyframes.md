# Больше двух кадров

`@keyframes` задаёт несколько точек. Им крутят индикатор загрузки или внимание к ошибке. Бесконечный цикл на большом блоке быстро утомляет и может нарушить reduced motion — это следующий урок, но уже здесь не ставьте вечную анимацию на весь экран.

Коротко: _keyframes — сценарий, transition — догон одного свойства_.
