# Три работы

Layout считает геометрию: ширина, высота, положение. Paint заливает пиксели: цвет, тень. Composite складывает слои: чаще всего `transform` и `opacity`.

Анимация `top` или `width` на каждом кадре трогает layout соседей. Та же иллюзия движения через `transform` обычно дешевле.

Коротко: _двигайте слой, не пересчитывайте страницу_.
