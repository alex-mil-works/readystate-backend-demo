# Не только движением

Если «сохранено» показано только прыжком галочки, тот, у кого анимация выключена или кто не смотрит в эту точку, статус не узнает. Нужны текст или смена подписи.

Автопроигрывание видео и бесконечный фон ставят на паузу при reduce. В компоненте, где жест считает скрипт, ту же медиа-функцию читают из JS и не запускают лишний rAF.

Коротко: _состояние видно без анимации_.
