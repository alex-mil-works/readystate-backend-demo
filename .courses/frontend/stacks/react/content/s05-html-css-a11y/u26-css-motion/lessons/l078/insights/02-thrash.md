# Чтение после записи

Записали `element.style.width`, тут же прочитали `offsetHeight` — браузер вынужден синхронно посчитать layout. В цикле по списку это layout thrashing.

Сначала прочитайте все размеры, потом запишите все стили. `will-change: transform` заранее поднимает слой, но на каждом блоке страницы он только ест память.

Коротко: _не чередуйте запись стиля и чтение геометрии_.
