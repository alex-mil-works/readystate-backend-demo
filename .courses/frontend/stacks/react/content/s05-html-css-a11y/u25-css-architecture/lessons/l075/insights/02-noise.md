# Когда шум побеждает

Длинная строка классов на каждом вложенном div трудно читается и копируется с расхождениями. Повторяющийся кусок — компонент с нормальным именем, внутри него утилиты или один модуль.

`@apply` на каждый чих возвращает обычный CSS и теряет обзор «что на элементе». Его оставляют для редкого базового слоя, не для всей кнопки в десяти вариантах.

Коротко: _повтор собирают компонентом, не простынёй @apply_.
