# Где живут стили

CSS-in-JS, который вставляет правила в рантайме, удобен для стилей от props, но добавляет работу при рендере и усложняет SSR. Модули и утилиты отдают обычный CSS на сборке.

Граница компонента: снаружи приходят данные и слоты, не селектор «покрась мой внутренний span». Тема кнопки — её вариант, не класс родителя с высокой специфичностью.

Коротко: _стиль от props возможен, но публичный API компонента важнее рантайма_.
