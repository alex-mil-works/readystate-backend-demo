# Имя блока

BEM: блок `card`, элемент `card__title`, модификатор `card--compact`. Стили не завязаны на голый `h2` по всему сайту, иначе одна правка заголовка заденет чужие экраны.

Не лезьте в внутренности чужого блока селектором `.card .button span`. Публичный вид кнопки — её собственные классы.

Коротко: _класс — контракт блока, не путь из тегов_.
