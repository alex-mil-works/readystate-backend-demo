# Токен, не разовый цвет

Sass и PostCSS умеют вложенность и переменные. Сегодня вложенность и custom properties есть и в CSS. Инструмент оправдан, если собирает токены и префиксы, а не если каждый блок заводит свой `#3a7bd5`.

Цвет текста, шаг отступа, радиус — переменные темы. Компонент ссылается на них. Новый оттенок серого — решение системы, не строки в модуле карточки.

Коротко: _палитра одна, компоненты её не расширяют молча_.
