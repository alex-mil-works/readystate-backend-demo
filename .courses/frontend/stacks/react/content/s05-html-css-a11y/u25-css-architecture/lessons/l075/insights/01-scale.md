# Шкала вместо случайных пикселей

Utility-класс вроде `mt-4` или `text-sm` берёт шаг из темы. Так реже появляется `margin: 13px` в одном компоненте и `15px` в другом.

Смысл блока при этом не в классах отступа. Кнопка остаётся `button`, карточка может собраться утилитами, но имя действия — в тексте и теге.

Коротко: _утилита задаёт токен, тег задаёт роль_.
