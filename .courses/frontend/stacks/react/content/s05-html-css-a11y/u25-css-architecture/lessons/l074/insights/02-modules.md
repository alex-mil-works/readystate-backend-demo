# Локальное имя

CSS Modules превращают `.title` в уникальный класс файла. Два компонента могут назвать класс одинаково и не перекрасить друг друга.

Глобальными оставляют сброс, токены и редкий каркас. Всё, что принадлежит карточке, живёт рядом с ней.

Коротко: _область видимости класса такая же важная, как область видимости функции_.
