# Заголовки — оглавление

Уровень заголовка — это структура, не размер шрифта. После `h1` идёт `h2`, не `h4` «потому что так красивее». Размер задаёт CSS.

`section` без заголовка не становится разделом в оглавлении. Если область не называется, это обычно `div`.

Коротко: _заголовок описывает раздел, класс описывает вид_.
