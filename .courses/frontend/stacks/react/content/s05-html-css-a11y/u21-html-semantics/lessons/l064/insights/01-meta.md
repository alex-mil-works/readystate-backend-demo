# Как страница называется снаружи

`lang` на `html` говорит, каким голосом читать. `title` — вкладка, история и часто заголовок в поиске. Meta description — подсказка для сниппета, не скрытый текст для пользователя.

```html
<html lang="ru">
  <head>
    <title>Урок: ориентиры документа</title>
  </head>
</html>
```

Один общий title на все уроки делает историю и вкладки бесполезными. Заголовок вкладки совпадает со смыслом экрана.

Коротко: _title и lang читают люди и роботы ещё до вашего компонента_.
