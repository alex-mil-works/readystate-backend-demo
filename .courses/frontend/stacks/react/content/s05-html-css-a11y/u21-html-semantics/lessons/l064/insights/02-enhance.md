# Сначала документ, потом улучшение

Progressive enhancement: ссылка и форма работают как HTML. Скрипт ускоряет и уточняет, но не единственный способ попасть в содержимое.

Кнопка, которая до гидрации ничего не делает и не является кнопкой, на медленной сети — мёртвая область. Ссылка на тот же URL остаётся ссылкой.

Коротко: _скрипт улучшает разметку, а не заменяет её_.
