# Текст вместо пикселей

У содержательной картинки `alt` говорит, что на ней важно. У декоративной `alt=""`: скринридер её пропустит. Имя файла вместо текста — плохой alt.

Таблица — для данных: `th` и `caption`. Для раскладки колонок она не нужна. У `video` оставляют `controls` и по возможности дорожку субтитров.

Коротко: _что нельзя увидеть, должно быть сказано текстом или разметкой_.
