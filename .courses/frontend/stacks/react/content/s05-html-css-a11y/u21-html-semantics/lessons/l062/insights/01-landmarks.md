# Ориентиры, не обёртки

`header`, `nav`, `main`, `aside`, `footer` попадают в дерево доступности как landmarks. Скринридер умеет прыгать по ним. `div` такого имени не имеет.

```html
<body>
  <header>…</header>
  <nav aria-label="Разделы">…</nav>
  <main>
    <h1>Курс</h1>
  </main>
</body>
```

`main` на странице один. Второй `nav` без подписи не отличить от первого: дайте `aria-label`.

Коротко: _ориентир называет область, div только группирует в вёрстке_.
