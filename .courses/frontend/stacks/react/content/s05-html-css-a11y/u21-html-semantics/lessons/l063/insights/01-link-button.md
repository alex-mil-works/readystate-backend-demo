# Адрес или действие

`a href` открывает URL: новое место, файл, якорь. Его можно открыть в новой вкладке и скопировать. `button` запускает действие на этой странице: сохранить, открыть диалог, сменить вкладку интерфейса.

```html
<a href="/courses/frontend/react">К курсу</a>
<button type="button">Сбросить прогресс</button>
```

Кликабельный `div` не попадает в tab и не объявляется как ссылка или кнопка. Если это переход — ссылка. Если команда — кнопка.

Коротко: _навигация — ссылка, команда — кнопка_.
