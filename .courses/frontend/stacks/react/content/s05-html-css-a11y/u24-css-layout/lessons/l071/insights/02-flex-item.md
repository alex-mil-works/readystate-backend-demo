# Как ребёнок занимает место

`flex: 1 1 auto` значит: расти, сжиматься, база по содержимому. Число в `flex: 1` — это grow. Длинный текст или картинка не сожмутся ниже минимума контента, пока не поставить `min-width: 0`.

Именно поэтому flex-колонка «вылезает» из карточки: у flex-элемента `min-width: auto`, он не уже своего текста.

Коротко: _flex-grow делит лишнее, min-width решает, можно ли сжаться_.
