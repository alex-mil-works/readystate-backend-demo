# Дорожки

`grid-template-columns` описывает колонки сразу. `1fr` — доля свободного места после фиксированных дорожек. `minmax(0, 1fr)` не даёт колонке раздуться от длинного слова.

```css
.page { display: grid; grid-template-columns: 240px 1fr; gap: 24px; }
```

Элемент кладут в ячейку по линиям или через `grid-template-areas`, если каркас читается именами: шапка, меню, контент.

Коротко: _сначала рисуют сетку, потом сажают в неё блоки_.
