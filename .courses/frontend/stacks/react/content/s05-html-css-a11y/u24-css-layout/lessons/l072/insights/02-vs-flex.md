# Grid или flex

Страница с колонкой меню и меняющимся контентом — grid. Ряд кнопок внутри тулбара — flex. Таблица данных по-прежнему `table`, не grid: у неё есть связь ячеек для скринридера.

Вложенность нормальна: страница на grid, карточка внутри на flex.

Коротко: _две оси сразу — grid, одна очередь — flex_.
