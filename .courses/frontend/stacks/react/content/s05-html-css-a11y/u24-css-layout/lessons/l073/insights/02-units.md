# Единицы и зум

`rem` считается от корня: пользовательский размер шрифта масштабирует интерфейс. `em` — от текущего шрифта элемента, удобен для паддинга кнопки. Голый `px` на тексте игнорирует настройку браузера.

`100vh` на мобильных часто выше видимой области из-за панелей браузера. `dvh` ближе к видимому куску. Запрет зума через `user-scalable=no` ломает доступность.

Коротко: _размер текста уважает настройку пользователя_.
