# Сначала узкий

Базовые стили — для маленькой ширины, одна колонка. `min-width` добавляет сложность, когда места хватает. Так проще, чем переопределять десктоп через `max-width` на каждом шаге.

```css
.cards { display: grid; gap: 16px; }
@media (min-width: 48rem) {
  .cards { grid-template-columns: 1fr 1fr; }
}
```

Брейкпоинт — про содержимое, которое перестало помещаться, а не про конкретный телефон.

Коротко: _узкая вёрстка по умолчанию, широкая — добавка_.
