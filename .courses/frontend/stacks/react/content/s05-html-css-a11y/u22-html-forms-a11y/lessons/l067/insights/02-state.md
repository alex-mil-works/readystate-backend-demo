# Состояние, не украшение

`aria-expanded` говорит, открыта ли панель. `aria-controls` связывает кнопку с её регионом. Иконка-шевроны этого не сообщают.

`aria-hidden="true"` убирает декоративную svg из дерева, если рядом уже есть текст. Не вешайте его на кнопку: она исчезнет для скринридера.

Коротко: _атрибут состояния совпадает с тем, что видно_.
