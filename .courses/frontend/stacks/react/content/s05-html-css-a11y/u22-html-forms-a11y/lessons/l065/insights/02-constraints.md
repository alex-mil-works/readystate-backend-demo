# Ограничения браузера

`required`, `type="email"`, `min`, `max` и `pattern` не дают отправить заведомо пустое или кривое значение. Сообщение браузера грубое, но проверка уже есть без библиотеки.

Группу радиокнопок связывают общим `name` и подписывают через `fieldset` и `legend`. Иначе скринридер не знает, что это один вопрос.

Коротко: _сначала ограничения платформы, потом свой текст ошибки_.
