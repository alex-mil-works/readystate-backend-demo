# Не чинить div ролью

Первое правило: не используйте ARIA, если есть подходящий HTML. `role="button"` не добавляет Enter и Space, не даёт type и не попадает в форму. Это объявление, не поведение.

```html
<!-- хуже -->
<div role="button" onclick="save()">Сохранить</div>
<!-- лучше -->
<button type="button">Сохранить</button>
```

Роль имеет смысл у составного виджета: вкладки, combobox, раскрывающаяся панель, если нативного тега нет.

Коротко: _ARIA называет виджет, клавиатуру вы пишете сами_.
