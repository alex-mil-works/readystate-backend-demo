# Фокус виден и логичен

Клавиатурный пользователь идёт по Tab в порядке документа. `tabindex` больше нуля этот порядок ломает. `-1` убирает из Tab то, что фокусируют скриптом, например контейнер диалога.

`outline: none` без замены прячет фокус. Если рисуете своё кольцо, оставьте его на `:focus-visible`, чтобы мышь не шумела, а клавиатура видела место.

Коротко: _фокус — это курсор клавиатуры, его нельзя стирать_.
