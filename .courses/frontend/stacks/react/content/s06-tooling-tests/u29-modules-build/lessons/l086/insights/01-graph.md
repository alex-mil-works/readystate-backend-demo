# Граф, не список файлов

Статический `import` виден без запуска файла. Сборщик идёт от входа и выкидывает то, до чего нет пути. Циклический импорт оставляет переменную неинициализированной: модуль ещё не закончил выполняться.

```js
import { Button } from './button';
export function Toolbar() {
  return Button;
}
```

Коротко: _в бандл попадает достижимое из входа, не вся папка src_.
