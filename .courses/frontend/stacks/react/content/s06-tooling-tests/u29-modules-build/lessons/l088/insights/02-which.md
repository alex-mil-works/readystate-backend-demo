# Кто для какой работы

Rollup исторически силён в библиотеках и ESM-чанках. Webpack долго тащил большие приложения с лоадерами. esbuild и SWC берут скоростью парсинга. Parcel продаёт ноль конфига. Vite в проде опирается на Rollup, в деве — на быстрый предбандл.

Знать все конфиги не нужно. Нужно понимать, какой шаг падает: синтаксис, ненайденный экспорт или разрезание чанка.

Коротко: _инструмент выбирают по задаче, не по длине конфига_.
