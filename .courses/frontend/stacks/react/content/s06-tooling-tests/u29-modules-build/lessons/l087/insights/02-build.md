# Прод — другой режим

Команда сборки проходит граф, минифицирует и режет чанки. Ошибка, которой не было в деве, всплывает здесь: неправильный импорт, нет дерева для node-модуля, переменная окружения не попала в клиент.

Точка входа Vite — `index.html`, не спрятанный конфиг вебпака. Скрипт в HTML и есть корень графа.

Коротко: _дев доказывает правку, build доказывает поставку_.
