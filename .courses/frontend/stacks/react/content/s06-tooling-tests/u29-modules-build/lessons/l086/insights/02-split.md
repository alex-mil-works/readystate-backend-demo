# Отложить тяжёлое

`import()` возвращает промис и даёт сборщику право положить модуль в отдельный файл. Им режут редкий экран, редактор, карту. Первый заход не должен качать то, что откроют один раз.

Общая зависимость двух чанков не обязана продублироваться: сборщик выносит её в общий кусок, если это выгодно.

Коротко: _режут по маршруту и по редкости, не по каждому файлу_.
