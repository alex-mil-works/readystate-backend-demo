# Быстрый дев, потому что нет полного бандла

Браузер сам грузит ESM. Vite отдаёт исходник по запросу и переписывает голые импорты в пути. Зависимости из node_modules один раз предсобирает быстрым бандлером: их много и они редко меняются.

HMR подменяет модуль, который изменился, и то, что от него зависит по границе. Состояние выше границы можно сохранить.

Коротко: _дев-сервер ленивый, он не собирает всё приложение на каждое сохранение_.
