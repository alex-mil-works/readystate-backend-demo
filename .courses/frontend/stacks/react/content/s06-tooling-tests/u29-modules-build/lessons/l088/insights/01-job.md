# Склеить и выкинуть мёртвое

Браузеру неудобно тянуть тысячи мелких файлов и синтаксис, который он не понимает. Бандлер проходит граф, переписывает импорты и может выкинуть неиспользуемый экспорт.

Транспилятор (tsc, Babel, SWC) превращает TS и JSX в JS. Сам по себе он не решает, какой чанк отдать первым экраном.

Коротко: _транспиляция меняет синтаксис, бандл собирает поставку_.
