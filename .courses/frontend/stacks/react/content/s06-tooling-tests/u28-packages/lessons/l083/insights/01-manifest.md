# Что обещает манифест

`dependencies` нужны, чтобы пакет работал у потребителя. `devDependencies` нужны, чтобы его собирать и проверять: тест-раннер, линтер, типы. `peerDependencies` говорят: эту библиотеку должен поставить хозяин приложения, а не вложенная копия.

Скрипты в `scripts` — общий язык команды. CI вызывает их, а не случайный набор флагов.

Коротко: _манифест — контракт пакета, не список всего, что когда-то ставили_.
