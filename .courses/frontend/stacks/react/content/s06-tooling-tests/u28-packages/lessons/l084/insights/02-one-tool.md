# Один инструмент на репозиторий

Локфайл у npm, pnpm и Yarn разный. Второй менеджер его проигнорирует или перепишет. В репозитории фиксируют один: `packageManager` в манифесте и соответствующий лок.

Команда в доке и в CI вызывает тот же бинарь, что и автор. «Просто npm install» в Yarn-проекте — другой граф.

Коротко: _менеджер — часть воспроизводимости, не вкус редактора_.
