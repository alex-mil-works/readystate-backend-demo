# Как лежит node_modules

npm поднимает зависимости вверх. Из-за этого пакет иногда импортирует то, чего нет в его манифесте: фантомная зависимость. На чистой установке импорт пропадёт.

pnpm хранит файлы в складе и даёт проекту жёсткие ссылки. Видеть можно только то, что объявлено. Yarn Berry умеет и классические node_modules, и Plug’n’Play без этой папки.

Коротко: _строгий граф ловит чужой импорт раньше, чем CI на другой машине_.
