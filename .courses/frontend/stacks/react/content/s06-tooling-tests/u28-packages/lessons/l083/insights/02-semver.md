# Цифра, которая ломает

Версия `major.minor.patch`. Патч чинит, не меняя API. Минор добавляет совместимое. Мажор может сломать вызов.

Диапазон `^1.4.2` для стабильной 1.x пускает минор и патч, но не 2.0.0. На 0.x каретка осторожнее: там минор часто и есть ломка.

Коротко: _диапазон — доверие к чужому SemVer, локфайл это доверие ограничивает_.
