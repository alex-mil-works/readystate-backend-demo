# Диапазон и точное дерево

Манифест говорит «подойдёт ^18». Локфайл говорит, какие именно версии и какие подзависимости стояли, когда команда это проверила. Без лока две установки в разные дни получат разные патчи.

Лок коммитят. В CI ставят с запретом его менять: `npm ci`, `pnpm install --frozen-lockfile`, `yarn install --immutable`.

Коротко: _диапазон для обновления, лок для повторяемости_.
