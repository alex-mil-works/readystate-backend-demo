# Пакет исполняется

Зависимость — чужой код: скрипты установки, импорты в бандл, доступ к сети на CI. Опечатка в имени (`react` и похожий пакет) и внезапный пост-инсталл — типичный путь атаки.

Аудит показывает известные дыры, но зелёный отчёт не доказывает, что пакет безвреден. Смотрят источник, сопровождение и нужен ли пакет вообще.

Коротко: _обновление зависимости — ревью кода, не только смена цифры_.
