# Что впекается в клиент

Vite кладёт в браузерный бандл только переменные, которые вы явно отдали клиенту, обычно с префиксом `VITE_`. Секрет без этого префикса в клиент не попадёт, а с префиксом попадёт и перестанет быть секретом.

Падение сборки читают снизу причины: не найден экспорт, цикл, тип, который стал ошибкой рантайма бандлера, нет файла. Первая строка «failed to build» сама ничего не чинит.

Коротко: _в клиенте нет секретов, в логе сборки есть модуль-виновник_.
