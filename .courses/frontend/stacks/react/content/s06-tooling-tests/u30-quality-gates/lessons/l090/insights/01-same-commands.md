# Одни команды

Типы ловят несогласованный вызов. Линтер — известные ловушки. Тесты — поведение, которое вы назвали. Сборка — что граф вообще собирается в поставку. Это разные вопросы, один зелёный не закрывает остальные.

Скрипты в package.json и есть контракт. CI копирует их, а не придумывает свой набор флагов.

Коротко: _если локально это не команда, в CI это случайность_.
