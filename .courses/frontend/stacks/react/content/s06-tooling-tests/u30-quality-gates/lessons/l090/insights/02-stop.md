# Красное останавливает

Ветка не становится общей, пока контур красный. Обход хука «только сейчас» оставляет ту же ошибку следующему. Ускоряют контур, а не выкидывают шаг: типы на изменённом проекте, тесты пакетом, e2e отдельно от каждого сейва.

Порядок обычно такой: формат и линт, типы, быстрые тесты, сборка. Медленный браузерный прогон — на основной ветке или по расписанию, но не вместо юнитов.

Коротко: _быстрое гоняют часто, медленное — на границе поставки_.
