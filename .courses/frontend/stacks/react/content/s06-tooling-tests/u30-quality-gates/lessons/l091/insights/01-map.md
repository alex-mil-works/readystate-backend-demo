# Карта обратно к файлу

Прод-стек показывает один сжатый файл. Source map говорит браузеру и отладчику, какая строка исходника этому соответствует. Без карты чинить продакшен по стеку почти слепо.

Карту не всегда отдают публично: в ней видны исходники. Её можно загрузить только в систему ошибок.

Коротко: _минификация для пользователя, карта для того, кто чинит_.
