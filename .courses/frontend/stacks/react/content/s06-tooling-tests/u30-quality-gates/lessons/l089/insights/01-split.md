# Смысл и пробелы

ESLint смотрит правила: забытый await, неиспользуемая переменная, опасный `any` в запрещённом месте, хук под if. Его можно настроить под проект и часть правил умеет чинить сама.

Prettier не спорит о логике. Он печатает файл в одном стиле, чтобы ревью не обсуждало запятые. Если оба правят одни и те же пробелы, они будут переписывать друг друга.

Коротко: _линтер про ошибки, форматтер про вид, пересечение выключают_.
