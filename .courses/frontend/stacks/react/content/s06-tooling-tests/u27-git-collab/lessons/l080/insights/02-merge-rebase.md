# Соединить или переложить

Merge создаёт коммит с двумя родителями и не переписывает уже существующие хеши. Rebase берёт ваши коммиты и кладёт их поверх другой вершины: хеши меняются.

Чужую опубликованную ветку, от которой уже оттолкнулись другие, rebase-ом не переписывают. Свою короткую ветку до PR — часто да.

Коротко: _merge сохраняет историю, rebase переписывает ещё не общую_.
