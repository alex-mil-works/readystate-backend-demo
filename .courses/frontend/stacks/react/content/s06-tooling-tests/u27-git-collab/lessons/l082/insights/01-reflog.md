# Коммит не пропадает сразу

Пока на объект есть ссылка, Git его хранит. Reflog — локальный журнал, куда указывали HEAD и ветки. «Потерянный» после reset коммит обычно ещё там.

```text
git reflog
git switch -c recover abc1234
```

Это журнал вашего клона, не сервера. На другой машине тех записей нет.

Коротко: _reflog — локальная история указателей_.
