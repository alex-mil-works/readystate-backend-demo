# Своя история и чужая

`origin` — именованный удалённый репозиторий. `fetch` скачивает объекты и двигает remote-tracking ветки, не вашу рабочую. `pull` — это fetch плюс соединение с текущей веткой.

Локальный `main` и `origin/main` могут указывать на разные коммиты, пока вы не забрали или не отправили.

Коротко: _fetch узнаёт, pull ещё и встраивает_.
