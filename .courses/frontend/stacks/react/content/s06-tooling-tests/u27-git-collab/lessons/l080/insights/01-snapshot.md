# Снимок, не папка diff

Коммит хранит состояние отслеживаемых файлов и ссылку на родителя. Сообщение говорит, зачем снимок сделан, а не перечисляет файлы.

```text
fix: не отправлять форму кнопкой показа пароля
```

Мелкий коммит с одной причиной проще откатить и проще прочитать через месяц.

Коротко: _коммит — именованный снимок, ветка — подвижная метка на нём_.
