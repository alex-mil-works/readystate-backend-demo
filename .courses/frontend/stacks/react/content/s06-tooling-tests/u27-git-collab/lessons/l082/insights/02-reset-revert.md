# Двигать ветку или отменить коммитом

`reset` перемещает ветку. `--soft` оставляет изменения в индексе, `--mixed` в рабочей копии, `--hard` выбрасывает незакоммиченное. На общей ветке это переписывание истории.

`revert` создаёт новый коммит, обратный выбранному. История вперёд, чужие клоны не ломаются. Для main это обычный путь отката.

Коротко: _на общей ветке отменяют новым коммитом, не стиранием прошлого_.
