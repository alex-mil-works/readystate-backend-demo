# Конфликт — не ошибка Git

Конфликт возникает, когда две стороны изменили одни и те же строки. Маркеры в файле показывают обе версии. Задача — оставить правильное поведение, а не «выбрать верхнее».

Маленький PR уменьшает площадь пересечения и даёт ревьюеру один вопрос, а не всю неделю работы.

Коротко: _PR — единица ревью, конфликт решают тестом и смыслом_.
