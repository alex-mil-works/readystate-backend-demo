# Не спать, а ждать

Хрупкий тест зависит от таймера, порядка анимации или общих данных с другим тестом. `sleep(1000)` то успевает, то нет.

Ждут локатор или ответ, который должен появиться. Каждый тест сам создаёт данные и не надеется, что прошлый оставил базу в нужном виде.

Коротко: _условие вместо паузы, изоляция вместо общего черновика_.
