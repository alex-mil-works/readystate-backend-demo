# Несколько компонентов вместе

Полезный тест формы рендерит поле и кнопку вместе, а не проверяет кнопку в изоляции от state. Это всё ещё не браузер: нет настоящего адреса и сети, если вы их не подменили.

События шлют через user-event, не через прямой вызов пропа onClick. Иначе вы обойдёте то, как клик доходит до обработчика.

Коротко: _компонентный тест — маленький сценарий экрана, не снимок реализации_.
