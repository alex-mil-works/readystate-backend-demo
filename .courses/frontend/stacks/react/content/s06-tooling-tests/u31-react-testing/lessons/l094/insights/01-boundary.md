# Только граница браузера

Playwright открывает страницу, кликает и читает DOM. Это дорого. Им проверяют путь, который не собрать из чистых функций: переход по URL, обновление страницы, форма до результата.

Каждую чистую функцию тащить в e2e — медленный дубль юнита. Набор сквозных сценариев короткий и про критичный путь.

Коротко: _e2e доказывает сборку экранов, не таблицу истинности_.
