# Одно поведение

Юнит отвечает на вопрос «при таком входе функция даёт такой выход». Ему не нужен экран, роутер и сеть. Vitest и Jest здесь почти одинаковы: тест, ожидание, мок модуля.

```ts
expect(pickRecall(pool, 2)).toHaveLength(2);
```

Падение должно называть поведение, которое сломалось, а не номер строки реализации.

Коротко: _юнит дешёвый, потому что не поднимает браузер_.
