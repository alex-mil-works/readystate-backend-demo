# Искать как пользователь

Testing Library рендерит компонент и даёт запросы: роль `button` с именем «Сохранить», подпись поля, текст статуса. Это те же зацепки, что у скринридера и у человека.

```tsx
render(<SaveForm />);
await user.click(screen.getByRole('button', { name: 'Сохранить' }));
expect(screen.getByText('Сохранено')).toBeInTheDocument();
```

Класс, testid на каждой ноде и «сколько раз вызвался useState» ломаются от вёрстки, хотя поведение живое.

Коротко: _тест кликает по роли и читает результат на экране_.
