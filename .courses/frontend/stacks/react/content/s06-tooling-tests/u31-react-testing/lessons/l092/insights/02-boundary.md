# Мок на границе

Сеть, часы и случайность подменяют, иначе тест то зелёный, то красный. Внутренние вызовы своей же функции мокать не нужно: вы привяжете тест к способу, а не к результату.

Фикстура — маленький кусок данных рядом с тестом. Живой API в юните делает контур медленным и зависимым от чужого сервера.

Коротко: _подменяют мир снаружи, результат проверяют снаружи_.
