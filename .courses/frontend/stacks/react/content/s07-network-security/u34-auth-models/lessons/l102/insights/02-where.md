# Где лежит и кто проверяет

Токен в `localStorage` любой скрипт вашего источника прочитает, и он переживёт перезагрузку. Переменная в памяти вкладки умирает вместе с ней, но скрипт, который уже выполняется на странице, прочитает и её: это не сейф от XSS, только менее удобная полка. Долгоживущее обновление чаще держат в HttpOnly-cookie, а короткий доступ не кладут туда, откуда его легко забрать.

Подпись проверяет сервер на каждом запросе. Проверка в браузере не граница: клиент сам себе не судья.

Коротко: _короткий доступ, отдельное обновление, проверка только на сервере_.
