# Доступ от имени, не пароль чужого сайта

OAuth даёт вашему приложению ограниченный доступ к ресурсу, не пароль пользователя от того сервиса. OIDC поверх этого говорит, кто вошёл: отдельное утверждение личности.

Согласие показывает провайдер. Фронтенд только начинает переход и принимает возврат. Объём доступа запрашивают минимальный.

Коротко: _мы просим разрешение, а не забираем чужой пароль_.
