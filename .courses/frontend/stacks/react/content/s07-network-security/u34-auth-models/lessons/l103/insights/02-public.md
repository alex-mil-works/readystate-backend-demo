# Клиент в браузере публичный

Секрет приложения в бандле секретом не является. Публичный клиент доказывает запрос иначе: код авторизации и проверка, что тот же клиент начал сценарий. Старый неявный возврат токена в адресе для новых приложений не берут.

Адрес возврата совпадает с заранее зарегистрированным. Иначе ответ провайдера уйдёт не туда. В журнал и аналитику код из адреса не пишут.

Коротко: _фронтенд начинает вход и не хранит секрет сервера_.
