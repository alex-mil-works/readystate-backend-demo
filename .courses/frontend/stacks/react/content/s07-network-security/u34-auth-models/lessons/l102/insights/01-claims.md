# Утверждения, не шифр

JWT — три части: как подписано, утверждения и подпись. Утверждения читаются. Подпись не даёт их тихо переписать, но не прячет от того, у кого токен уже есть.

Туда кладут идентификатор и срок, не пароль и не ключ подписи. Срок делают коротким: украденный доступ быстро протухает.

Коротко: _кто держит токен, тот читает утверждения; переписать их без ключа нельзя_.
