# Чужой сайт, ваша cookie

Если сессия живёт в cookie, браузер приложит её и к запросу, который начал чужой сайт. Это и есть риск межсайтовой подделки: пользователь уже вошёл, а запрос на изменение ушёл не из вашего интерфейса.

`SameSite=Lax` режет большую часть таких переходов для небезопасных методов. Для оставшихся меняющих запросов сервер ждёт отдельное подтверждение, которое чужая страница не может прочитать с вашего источника.

Коротко: _cookie доказывает браузер, не то, что кликнули в вашем UI_.
