# Браузер прикладывает сам

Cookie хранит браузер и сам прикрепляет к запросам на подходящие домен и путь. `Secure` не отдаёт её по голому http. `HttpOnly` не даёт прочитать её из JavaScript. `SameSite` сужает, уйдёт ли она с чужого сайта.

Идентификатор сессии на сервере лучше, чем складывать роль и права внутрь cookie, которую потом кто-то подправит. Сервер по id достаёт свою запись.

Коротко: _cookie — пропуск, который браузер носит сам, не поле в вашем state_.
