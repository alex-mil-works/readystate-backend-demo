# Откуда можно скрипту

Content-Security-Policy говорит браузеру, какие источники скриптов, стилей и кадров допустимы. Политика с запретом встроенных скриптов режет целый класс ошибок, даже если одну строку забыли экранировать.

CSP не заменяет границу текста. Если политика дырявая или её нет, сырой HTML снова исполняется. Заголовок отдают с сервера, его не «включают» из уязвимого скрипта.

Коротко: _сначала не вставлять HTML из данных, потом сузить источники скрипта_.
