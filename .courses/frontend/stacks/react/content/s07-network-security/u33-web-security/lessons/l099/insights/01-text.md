# Текст не разметка

XSS — это чужой скрипт в вашем источнике. Он видит всё, что видит страница: DOM, хранилище, запросы от имени пользователя.

Строку из комментария, имени или query нельзя класть в `innerHTML` и в разметку, собранную конкатенацией. Её вставляют как текст. В React это обычные фигурные скобки, не сырой HTML.

Коротко: _данные и разметка не смешиваются_.
