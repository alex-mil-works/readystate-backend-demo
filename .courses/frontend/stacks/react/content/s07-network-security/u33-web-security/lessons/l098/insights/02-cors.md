# Разрешение читается браузером

CORS — заголовки сервера, по которым браузер решает, можно ли отдать тело скрипту. Сервер без этих заголовков всё равно мог ответить. Другой HTTP-клиент CORS не спрашивает.

Звезда в разрешении источника не сочетается с учётными данными. Cookie на чужой источник уйдут только если сервер назвал конкретный origin и разрешил credentials, а клиент их запросил.

Коротко: _CORS — согласие на чтение в браузере, не авторизация действия_.
