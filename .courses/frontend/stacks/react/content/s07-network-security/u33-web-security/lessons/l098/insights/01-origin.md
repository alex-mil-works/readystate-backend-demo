# Одна тройка

Источник — схема, хост и порт. `https://app.example` и `http://app.example` разные. Поддомен тоже другой источник. Политика того же источника не даёт скрипту прочитать ответ чужого источника.

Запрос при этом часто уходит. Запрет — на чтение ответа скриптом, не на само существование сети.

Коротко: _другой источник — чужой ответ, пока браузеру не сказали иначе_.
