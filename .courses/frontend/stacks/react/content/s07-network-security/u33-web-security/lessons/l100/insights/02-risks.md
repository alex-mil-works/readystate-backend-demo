# Что ломают снова и снова

На фронте чаще всего всплывают: чужой скрипт в странице, слишком широкие права запроса, секрет в бандле, дырявая зависимость. Списки вроде OWASP полезны как карта, не как чеклист «поставим галочки».

Пакет из реестра попадает в бандл пользователя. Обновление и ревью лока из прошлого этапа — часть этой границы, не отдельная гигиена.

Коротко: _секрет живёт на сервере, в клиент уезжает только то, что можно показать_.
