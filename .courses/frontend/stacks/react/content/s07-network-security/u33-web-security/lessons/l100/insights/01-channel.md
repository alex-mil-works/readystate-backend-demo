# Канал не равен правам

HTTPS даёт конфиденциальность и целостность по дороге и привязывает имя к сертификату. Он не знает, можно ли этому пользователю открыть чужой урок. Это проверка на сервере.

Смешанная страница тянет часть ресурсов по http. Браузер такое режет или помечает: иначе шифрованный документ снова читается по пути через картинку или скрипт.

Коротко: _шифруется дорога, решение о доступе принимает приложение_.
