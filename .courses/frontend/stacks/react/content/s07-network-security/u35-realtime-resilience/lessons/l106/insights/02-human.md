# Человеку, не стеку

Пользователь видит, что сломалось на его языке и какую кнопку нажать: войти, обновить, исправить поле. Трассировку и SQL оставляют в системе ошибок.

Пустой список, ошибка загрузки и офлайн — три экрана. Пустой успешный ответ не красят как сбой. Офлайн не маскируют под 500.

Коротко: _восстановление видно, внутренняя причина остаётся у вас_.
