# Один эффект и отмена

Повтор POST безопасен, только если сервер узнает тот же запрос: ключ идемпотентности или идемпотентный метод. Иначе вторая попытка — второе действие.

Уход со экрана отменяет запрос сигналом. Молча не писать ответ в state недостаточно: работа на сети ещё идёт, а поздний ответ может относиться уже к другому экрану.

Коротко: _повтор не плодит эффект, отмена останавливает работу_.
