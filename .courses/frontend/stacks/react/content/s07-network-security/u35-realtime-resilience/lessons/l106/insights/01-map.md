# Статус диктует действие

401 — сессия кончилась, нужен вход, а не ещё одна попытка тех же данных. 403 — прав нет, повтор бесполезен. 404 — этой сущности нет. 409 — состояние уже другое, покажите актуальное. 422 — поправьте поля. 5xx и обрыв — временные, их можно предложить повторить.

Одна плашка «что-то пошло не так» прячет единственное полезное действие.
