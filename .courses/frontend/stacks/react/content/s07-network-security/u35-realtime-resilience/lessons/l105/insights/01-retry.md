# Не каждый статус стоит повтора

Обрыв и 503 можно попробовать снова. 400 и 422 повтор не исправит: запрос неверный. 401 значит «сначала войдите», не «шлите то же пять раз».

Между попытками ждут дольше и добавляют случайный разброс, чтобы все клиенты не ударили в сервер в одну миллисекунду. Лимит попыток конечный.

Коротко: _повторяют временный сбой, с паузой и не бесконечно_.
