# Не заменять запрос каналом

«Сохранить» — это запрос с статусом, телом ошибки и идемпотентностью. Тащить его в сокет значит потерять кэш, коды HTTP и понятную отмену.

Редкие новости можно и опрашивать. Поток окупается, когда задержка и частота не дают опрашивать честно.

Коротко: _канал выбирают по направлению и частоте, не по моде_.
