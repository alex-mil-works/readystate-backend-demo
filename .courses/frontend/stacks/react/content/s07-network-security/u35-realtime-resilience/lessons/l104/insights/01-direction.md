# Кто говорит

Server-Sent Events — один долгий HTTP-ответ, сервер дописывает события, браузер умеет переподключиться. Направление одно: к клиенту.

WebSocket после рукопожатия двусторонний: удобно для совместного редактирования и игры, где клиент шлёт так же часто, как слушает. Свой протокол поверх сокета вы поддерживаете сами, включая повторное соединение.

Коротко: _односторонний поток — событие HTTP, постоянный диалог — сокет_.
