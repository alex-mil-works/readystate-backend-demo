# Свежее и общее

`Cache-Control` говорит, сколько ответ можно считать свежим и можно ли делить его между людьми. Имя файла с хешем сборки можно кэшировать надолго: байты не изменятся. HTML приложения — нет, иначе пользователь не увидит новый вход.

Чужой или личный ответ (лента, профиль) с `public` осядет в общем кэше. Для него нужен `private` или запрет кэша.

Коротко: _неизменный файл кэшируют надолго, личный HTML — нет_.
