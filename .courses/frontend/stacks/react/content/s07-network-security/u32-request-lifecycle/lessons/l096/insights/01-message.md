# Две половины сообщения

Стартовая строка запроса: метод и путь. Дальше заголовки и необязательное тело. Ответ начинается со статуса. Тело интерпретируют по `Content-Type`, не по расширению файла в голове.

Класс статуса важнее конкретной цифры на первом чтении: 2xx удалось, 3xx ищите в другом месте, 4xx ошибка запроса, 5xx не справился сервер.

Коротко: _статус говорит, удалось ли, заголовок говорит, как читать тело_.
