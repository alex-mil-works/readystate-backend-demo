# Из чего адрес

В URL есть схема (`https`), хост, порт, путь, query и фрагмент после `#`. Фрагмент браузер оставляет себе: на сервер уходит путь и query, не якорь.

```text
https://app.example.com:443/courses/react?role=fe#L095
```

Схема решает, будет ли шифрование. Порт по умолчанию для https — 443, его в строке часто не пишут, но в origin он участвует.

Коротко: _хост — имя, не IP; решётка — не часть запроса_.
