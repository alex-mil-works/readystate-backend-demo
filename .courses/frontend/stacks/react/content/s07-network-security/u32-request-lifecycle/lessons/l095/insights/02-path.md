# Имя, соединение, сертификат

DNS сопоставляет хост с адресом. TCP устанавливает соединение. TLS поверх него проверяет сертификат: что имя в адресе совпало с тем, за кого выдаёт себя сервер, и что цепочка доверия жива.

Статика может лежать на CDN у края сети. Приложение за ней — отдельный процесс. Браузер всё равно говорит с тем IP, который получил для этого хоста.

Коротко: _сначала имя, потом канал, потом доверие к имени_.
