# Критический путь

Сначала приходит HTML. Браузер обнаруживает стили и скрипты и качает их, часто по тому же соединению. Пока нет CSS, рисовать рано: будет вспышка без стилей. Скрипт в голове без async/defer останавливает разбор.

Дальние картинки ниже экрана можно грузить позже. То, что нужно для первого кадра, на критическом пути.

Коротко: _HTML — оглавление загрузки, не вся страница_.
