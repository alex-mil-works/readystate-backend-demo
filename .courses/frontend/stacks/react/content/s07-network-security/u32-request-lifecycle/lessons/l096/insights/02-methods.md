# Повтор и безопасность

GET не должен ничего менять. Его можно повторить и закэшировать. PUT и DELETE по контракту идемпотентны: повтор с тем же смыслом не плодит второй эффект. POST таким не обещан: второй клик «оплатить» может создать второй заказ.

Код 404 — это ответ. Обрыв сети — отсутствие ответа. Путать их в UI значит показывать «не найдено» там, где нет связи.

Коротко: _метод обещает, можно ли повторить; статус — чем закончился этот раз_.
